codex command

The codex bundle sends a compact summary of the current ChimeraX session to the currently selected AI CLI backend and returns the reply.

Commands

codex auto [true|false]
codex backend [name]
codex model [name|default]
codex routing [ai-first|local-first|backend-only]
codex selftest
ai <text>
codex ask <text>
codex context [includeModels true|false] [includeSelection true|false]
codex tool
/scene save [name] [note...]
/scene load [name] [frames]
/scene info [name]
/scene note <name> <text>
/scene list

Examples

Align these two structures using only the catalytic core
codex auto false
codex backend gemini
codex model gemini-2.5-flash
codex routing ai-first
codex selftest
ai align #2 to #1 using only the catalytic core
/scene save pocket_closeup inward-facing candidate
/scene info pocket_closeup
codex context
codex ask Align #2 to #1 using only the catalytic core.
codex context includeSelection false
codex tool

Notes

  • When natural-language fallback is enabled, unknown multi-word input in the ChimeraX command line is sent to Codex automatically.
  • ai is the auto-run mode. It asks Codex for ChimeraX commands and executes them immediately.
  • codex backend changes the active AI CLI backend.
  • codex model overrides the model for the active backend.
  • codex routing controls whether natural-language requests prefer local rules or real AI backends.
  • codex selftest runs an in-app diagnostic for backend availability and natural-language parsing hints.
  • /scene ... provides lightweight figure-bookmark save/load/info commands built on ChimeraX named views plus extra metadata such as caption, legend, and notes.
  • The bridge expects a working local AI CLI such as codex, claude, or gemini.
  • The attached context is a summary of model IDs, names, and selection ranges, not a full structure export.
