Codex Action Pad

Codex Action Pad is a PyMOL-style action panel for ChimeraX. It lists open models and chains and provides small action menus for selecting, showing, hiding, labeling, coloring, and sending focused requests to the AI workspace.

Usage

  1. Open the pad with codex actions or from the Tools menu.
  2. Use the tree to choose a model or chain row.
  3. Use the object tree for A/S/H/L/C row actions.
  4. Use the action buttons:
    • A: select, focus, AI analyze, AI improve view
    • S: show cartoon, sticks, surface, or all
    • H: hide cartoon, atoms, surface, or all
    • L: apply labels or clear labels
    • C: recolor by chain, by model, or preset colors
  5. Use AI Tab to bring the terminal-style AI workspace forward.
