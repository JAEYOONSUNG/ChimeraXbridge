Codex Assistant

Codex Assistant is a ChimeraX-integrated AI workspace for asking the selected AI CLI backend, such as Codex, Claude, or Gemini, for structure-aware analysis, visualization planning, and interactive command execution.

Usage

  1. Open the tool with codex tool or from the Tools menu.
  2. Use the control bar to switch backend, mode, and speed profile. The default mode is agent, which can directly change the ChimeraX scene.
  3. Use the Quick popup for fast mode/backend/model preset switching, or Analysis for grouped local, sequence, modeling, and structure-search actions.
  4. Use Action Pad to open the PyMOL-style target panel with embedded display controls.
  5. Review the live workspace pane for current ChimeraX context, selection focus, and figure recommendations.
  6. Use quick buttons such as Analyze Sel, Improve View, Explain Site, or Best Figure for integrated workflows.
  7. Type a request into the prompt at the bottom of the transcript and press Enter to run the agent, or Shift+Enter to insert a new line.
  8. Use the in-app terminal for raw commands: plain input runs ChimeraX commands, and lines starting with ! run shell commands.
  9. Double-click an interactive suggestion or use Apply Suggestion to push an AI recommendation back into ChimeraX.

The right pane behaves like a terminal transcript. It keeps your request, live progress messages, executed ChimeraX commands, and final summaries in one continuous history. The left pane stays synchronized with ChimeraX selection and command changes so the tool can be used as a structure-analysis workbench instead of a standalone chat box.
